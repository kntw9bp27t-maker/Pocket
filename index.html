Pocket HTML

Open HTML files kept on this phone. Nothing is uploaded to a server.

Pick an HTML file together with its CSS, JS and images, or pick a .zip of the whole folder. Links between pages in a zip work.
Tips and limits
  • In the iPhone file picker, tap Select to choose several files at once.
  • For a site with subfolders, zip the folder first (Files app: long-press the folder, then Compress), then add the .zip.
  • Use ⋯ → Add files to add a missing image or stylesheet to an existing project.
  • Pages that load data with fetch(), use ES-module import between files, or load things from the internet may not fully work.
  • Files are stored in this browser only. Deleting browser or Claude app data removes them, so keep your originals.
